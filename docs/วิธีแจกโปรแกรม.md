# วิธีแจกโปรแกรม EditorStage ให้คนอื่น (ฉบับง่าย)

ทำแค่ 3 ขั้นตอนนี้

---

## ขั้นที่ 1 — หาไฟล์ติดตั้ง (มีอยู่แล้ว)

โฟลเดอร์ที่พร้อมแจกอยู่ที่:

```
D:\BYS All Stages Projects\EditorStage\release\EditorStage 3.2.0\
├── EditorStage Setup 3.2.0.exe     ← ตัวติดตั้ง
└── อ่านก่อนติดตั้ง.txt               ← วิธีติดตั้งสำหรับผู้ใช้
```

ในไฟล์ติดตั้งมีครบแล้วทั้งเอกสาร license และ **source code ของ FFmpeg กับ libvips**
(สองตัวนี้มีเงื่อนไขว่าถ้าแจกโปรแกรม ต้องแจก source ไปด้วย ตอนนี้ติดไปกับตัวติดตั้งเลย
ไปอยู่ที่ `โฟลเดอร์ที่ติดตั้ง\resources\source-code` ไม่ต้องแยกโฟลเดอร์แล้ว)

> ถ้าแก้โปรแกรมแล้วอยากได้ไฟล์ติดตั้งตัวใหม่: เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์ `npm run dist:win` รอจนเสร็จ ไฟล์ใหม่จะอยู่ในโฟลเดอร์ `release`

---

## ขั้นที่ 2 — เตรียมข้อความ "อ่านก่อนติดตั้ง.txt" (มีอยู่แล้ว)

ถ้าจะทำโฟลเดอร์ใหม่เอง ให้ copy ข้อความนี้ไปวาง:

```
EditorStage 3.2.0 — All rights reserved by BYS & RB

วิธีติดตั้ง
1. ดับเบิลคลิก "EditorStage Setup 3.2.0.exe"
2. ถ้า Windows ขึ้นหน้าจอสีฟ้า "Windows protected your PC"
   ให้กด "More info" แล้วกด "Run anyway"
   (ขึ้นเพราะโปรแกรมยังไม่ได้ซื้อใบรับรองลายเซ็นดิจิทัล ไม่ใช่ไวรัส)
3. กด Next ไปจนจบ

ดูรายละเอียด license ในโปรแกรมได้ที่เมนู Help > Third-Party Notices
source code ของ FFmpeg และ libvips (ส่วนประกอบในโปรแกรม) ติดตั้งมาพร้อมโปรแกรมแล้ว
อยู่ในโฟลเดอร์ที่ติดตั้ง > resources > source-code
```

---

## ขั้นที่ 3 — อัปโหลดแล้วแชร์ลิงก์

1. อัปโหลดโฟลเดอร์ `EditorStage 3.2.0` (หรือแค่ไฟล์ `.exe` ก็ได้) ขึ้น Google Drive, OneDrive, Mega หรือที่ไหนก็ได้
2. ตั้งค่าแชร์เป็น "ทุกคนที่มีลิงก์ดูได้"
3. ส่งลิงก์ให้คนอื่น

---

## คำถามที่อาจสงสัย

**ถ้ามีคนทักมาขอ source code ต้องทำไง?**
บอกเขาว่าอยู่ในเครื่องแล้ว ที่ `โฟลเดอร์ที่ติดตั้ง\resources\source-code` (ถ้าติดตั้งแบบ "เฉพาะฉัน" ซึ่งเป็นค่าเริ่มต้น คือ `%LOCALAPPDATA%\Programs\EditorStage\resources\source-code`
ถ้าเลือก "ทุกคนในเครื่อง" คือ `C:\Program Files\EditorStage\resources\source-code`)
หรือส่งไฟล์ในโฟลเดอร์ `third_party_source` ของโปรเจกต์ให้เขาก็ได้

**ต้องส่ง source code ของ EditorStage เองไหม?**
ไม่ต้อง โค้ดของ EditorStage เป็นของคุณ (All rights reserved) ที่ต้องให้มีแค่ source ของ FFmpeg กับ libvips

**ข้อความ All rights reserved by BYS & RB อยู่ตรงไหนในโปรแกรม?**
- มุมขวาบนของหน้าต่างโปรแกรม (แถบด้านบน)
- เมนู Help > About EditorStage...
- คลิกขวาที่ไฟล์ .exe > Properties > Details (ช่อง Copyright)
- ใน Windows: Settings > Apps (ช่อง Publisher เป็น BYS & RB)

**ออกเวอร์ชันใหม่ต้องทำอะไรบ้าง?**
1. แก้เลขเวอร์ชันในไฟล์ `package.json` (บรรทัด `"version": "3.2.0"`)
2. พิมพ์ `npm run dist:win`
3. อัปโหลดไฟล์ติดตั้งตัวใหม่

ถ้าอัปเดต FFmpeg หรือ libvips เป็นเวอร์ชันใหม่ ตอน `npm run dist:win` จะหยุดและบอกว่าขาดไฟล์ไหน พร้อมลิงก์ดาวน์โหลด
ให้โหลดไฟล์นั้นมาใส่ในโฟลเดอร์ `third_party_source` แล้วสั่งใหม่ (ไฟล์เวอร์ชันเก่าในโฟลเดอร์นั้นลบได้)

**อยากทำให้ครบตามกฎ GPL แบบเคร่งครัดที่สุด (ไม่บังคับ)**
FFmpeg ตัวที่ใช้ยังมีไลบรารีย่อยฝังอยู่ เช่น x264 และ x265 ถ้าจะให้ครบที่สุด ให้โหลด source ของไลบรารีพวกนั้น (ไฟล์ `.tar.xz`) ใส่ใน `third_party_source` ด้วย ตัวติดตั้งจะรวมไปให้อัตโนมัติ
รายชื่อไลบรารีอยู่ที่ https://www.gyan.dev/ffmpeg/builds/ (หัวข้อ release essentials)
ถ้าแจกฟรีกันในวงเล็กๆ ส่วนใหญ่ใส่แค่ FFmpeg กับ libvips ก็พอ
